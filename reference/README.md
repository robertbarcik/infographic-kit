# Reference images

The kit was designed against two reference pages supplied privately by a student. They are
not published here. Put your own reference images in this folder if you want to tune the
style against them; `*.png` in this folder is ignored by git.

`specs/00-protocols.json` and `specs/00-hosts-clients.json` re-create the content of those
two pages with the kit's own engine; their renders are in `gallery/`.
